<h3>Commands and Their Uses</h3>

1. "pwd" — Print Working Directory

This command displays the path of the current working directory.

2. "dir" — List Files and Folders

This command displays all files and folders available in the current directory.

3. "cd foldername" — Change Directory

This command is used to move into a specific folder.

Example: "cd Documents"

4. "cd .." — Move to the Parent Directory

This command moves one level up from the current directory.

5. "cd ~" — Go to the Home Directory

This command takes us to the user's home directory.

6. "mkdir foldername" — Create a New Folder

This command creates a new folder in the current directory.

Example: "mkdir HTML-Practice"

7. "cls" — Clear the Terminal Screen

This command clears the terminal screen in Windows Command Prompt or PowerShell.

Practice Tasks

1. Display the current working directory using "pwd".
2. List the files and folders using "dir".
3. Navigate to the Documents folder using "cd Documents", if available.
4. Move to the parent directory using "cd ..".
5. Create a new folder named "HTML-Practice" using "mkdir HTML-Practice".
6. Verify that the folder has been created using "dir".
